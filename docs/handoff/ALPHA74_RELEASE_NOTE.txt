alpha74: a speed, video-smoothness and security pass over the whole browser (every finding of the review was checked against the code before anything was changed). SPEED: the ad and tracker check that runs for every request no longer tries about 450 rules that cannot apply to the page; on the full list that is 33 percent less work per request on a desktop with identical verdicts (11.8 million checks compared old against new), and it should save more on the tablet, which has not been measured. VIDEO SMOOTHNESS: when the link drops in the middle of a film in Kestrel's own player (full screen or inside the page) the film is no longer ended: it waits and tries again up to four times, a failed piece is retried longer once the picture has started, and the Play button after an error now really starts it again; downloads now slow down while a film plays in Kestrel's own player (about 250 KB/s on the capped hotspot, under the same Settings switch as for loading pages, which is now called Slow downloads while a page loads or a video plays) so the film does not fall to a blurry picture or stall; the 480p limit now includes the usual 854 by 480 picture size (it used to fall to 360p); the first guess of the link speed now also applies behind the fast Wi-Fi tunnel. SECURITY: a web page can no longer aim Kestrel's own player at the router, a NAS or any other device on your network (every spelling of such an address is now recognised, and the player only opens web addresses); a web page can no longer freeze the browser with a crafted answer that hides video addresses (the address finder is bounded now); update file names that are not plain are refused and the release data is read with a size limit; private tabs no longer leave their site name in the Diagnostics. Not tested on the tablet: all of this was built and tested on a computer and in the build checks; the video retry in particular needs a real dropout on the hotspot to prove it.
