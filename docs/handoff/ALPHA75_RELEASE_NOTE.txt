alpha75: better page compatibility and a cleaner video list. PAGE COMPATIBILITY: Kestrel G now carries Mozilla's own list of fixes for sites that break in other browsers, the same list stock Firefox for Android has and this app was missing. It covers hundreds of sites (321 cases for phones in this version): pages that say your browser is unsupported, phone pages that open as desktop pages, broken sign-in scripts, and sites that only work when they see a different browser name (for example LinkedIn, CNN, Office 365 and Outlook, TikTok comments, several banks, Nintendo). It starts 12 seconds after the first page of a session has loaded, so opening the app is not slower, and it adds no network traffic of its own: the list that comes with the build is used and is renewed when the engine is updated. Settings, Network lab, Site fixes from Mozilla turns it off at once; Diagnostics shows a Site fixes line. VIDEO FINDING: the video finder was run against real players from the build computer for the first time (hls.js, video.js, Plyr, JW Player, Vimeo, Streamable, archive.org, MDN, Wikimedia): every stream and file that was playing was found with its right size. One fix came out of it: a web page whose address merely ends like a video file (Wikimedia File pages are one) could be counted as a video of the size of the page; a web page reply is no longer taken as a file size. WHAT I COULD NOT PROVE ON THE TABLET: on the emulator with the real Firefox engine the site fixes start in 0.2 seconds, cause no script errors and no extra memory (peak 298 MB against 303 MB before), but no emulator page was one that Mozilla has a fix for, so the fixes themselves are not seen working, and nothing was timed on the tablet.
