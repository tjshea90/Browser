alpha68: Kestrel now always types through your Swoop keyboard when it is installed, so there is one keyboard and one memory for both apps. Words you type or glide in Kestrel (the address bar, the home search box, the boxes of a web page) teach Swoop, and everything Swoop learned elsewhere is used in Kestrel. The address bar and the home box tell Swoop they are the browser address box, so Swoop shows its browser keys (slash, full stop, Go) and does not add capitals or spaces. In a private tab Swoop learns nothing from the page boxes either. If Swoop is installed but not chosen yet, the small panel's keyboard button opens Android's keyboard picker. Settings has Always use the Swoop keyboard (recommended) and a button that sends what Kestrel's own small keyboard learned to Swoop (Swoop asks before it adds anything). Kestrel's own small keyboard stays as the fallback when Swoop is not installed, and it got the new word list. Install Swoop 0.5.0-alpha4 or newer first. Checked on a simulated Android 10 tablet with the real Firefox engine: typing and gliding into page boxes and the address bar, private tabs, pages loading. NOT proven on the tablet or the phone: opening Swoop floating from the panel, the keyboard picker, the hand-over button.
