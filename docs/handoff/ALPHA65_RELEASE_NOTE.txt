alpha65: compile at install, the one thing you said go to. Until now an update was only checked by Android when it installed, and its code then ran in the slow interpreter until the tablet was idle and charging (and every update started that over). Now each release also carries a 7 KB start-up profile file. The updater in this version fetches it, checks it, and hands it to Android next to the APK, so Android compiles the update while it installs (in the test phone: 3.7 MB of compiled code from the first start, install 0.4 seconds slower). If Android ever refuses the file the updater installs the update once more without it and stops sending it for two weeks; on other Android versions, for releases without the file, or when storage is tight, the install is exactly what it was. IMPORTANT: this only helps updates that come FROM a version that has this updater, so the update to alpha65 is still compiled the old way and the first one compiled at install is the update after it. Nothing else changed. NOT proven on the tablet: Android Go may not honour the file (then nothing is gained and nothing is lost). If an update ever fails to install, tell me the exact words Android shows.
