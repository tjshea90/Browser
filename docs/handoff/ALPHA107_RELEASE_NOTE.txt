alpha107: Auto-tune, the automatic settings tester you asked for. Settings, Auto-tune, Start. It finds the best speed settings for this tablet by itself in about an hour and tells you what it kept. HOW IT WORKS: it restarts Kestrel once into a clean start (your tabs come back afterwards), then tries 20 experiments one by one. Each one changes ONE setting (drawing on the graphics chip, calmer redrawing, cheaper gradients, script compile and clean-up settings, style threads, scroll feel, Firefox 161's new settings and more), restarts the engine when the setting needs it, and runs the same fixed test pages: script speed, page layout, three animation tests (one is a strip of looping clips like the sports-odds page), scrolling, typing and tap wait, and 27 compatibility checks. It measures the tablet's own noise from baselines taken before, during and after, and keeps a setting only if it beats three times that noise in every sample, uses no more extra memory than allowed and breaks no compatibility check. Then it tries the kept settings together and keeps the combination only if it is as good as the best single one. WHAT IT ASKS YOU: what matters most to you; to plug the tablet in and turn Battery Saver off; and, only after a drawing test, one question: is any text cut off or covered? WHAT IT NEVER TOUCHES: Shields, tracking protection, HTTPS, encrypted DNS, cookies and fingerprint settings, certificates, and everything else about privacy and security. SAFETY: if Kestrel cannot start with a test setting, or you stop it, leave the app, or the battery runs low, it goes back to your own settings and waits. The report has an Undo button that puts your earlier settings back. RESULTS: when diagnostics sending is on, every number and every decision goes to the private repository for Claude; the button Send the results to Claude does it by hand. TESTED: the decision rules with simulated runs (including a kill at every step), the test pages in a desktop browser engine, and a short run of the whole thing on a pretend Android 10 tablet (RESULT_PLACEHOLDER). NOT run on your real tablet: the size of every effect, how the restarts behave on Android 10 Go, and how closely the clip test matches the sports-odds page. LEFT OUT FOR NOW: experiments about network speed (the hotspot's noise is bigger than their effect).
