## Emulator (how to repeat; ~5 min)
`sdkmanager --install emulator "system-images;android-29;default;x86"`; avdmanager create (device pixel_c), set config.ini to hw.lcd 600x973 @170, ram 2048, heap 128;
`emulator -avd <name> -no-window -no-audio -no-snapshot -no-boot-anim -gpu swiftshader_indirect -no-accel -wipe-data`. ARM images do NOT run on this x86_64 host; KVM absent -> `-no-accel`.
`adb install -r app/build/outputs/apk/release/app-release.apk`; test pages in a local `python3 -m http.server` reachable at `http://10.0.2.2:8000/` (IP literal => http allowed).
AOSP Android 10 image WebView = com.android.webview 74.0.3729.185 (no `?.`, `??`, `Array.at`, `replaceAll`, `:has`).
