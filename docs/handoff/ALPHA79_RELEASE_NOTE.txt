alpha79: attaching a file on a web page (your Google Gemini report), a first fix that is NOT proven on your tablet. When a page asks for a file, Kestrel opens Android file chooser; if that failed for any reason it did so silently and the page just waited, which is what you saw. Changed: (1) if no app on the tablet can choose a file, Kestrel now says so on screen (No app on this tablet can pick a file. Install a file manager.) and answers the page at once, instead of leaving it stuck; (2) when the usual chooser (Get content) has no app it falls back to the second kind of chooser (Open document); (3) the list of file kinds shown is fixed: a page that accepts pictures plus .pdf or .docx used to get a chooser that showed pictures only, because extensions were dropped, so the documents were hidden; now extensions are understood, and a list Kestrel cannot read means no filter at all, so no file is hidden; (4) a page that asks for a whole folder is answered at once with a message instead of waiting; (5) on Android 11 and later the app can now see the file chooser apps (it declared none); (6) Diagnostics has a new line File chooser: how many times a page asked, how many times the chooser opened, how many had no chooser app, how many times nothing was chosen, how many files were handed to the page, and the last thing that happened. If Gemini attachment still does nothing, open the menu, then Diagnostics, copy the line File chooser and send it: it says exactly where it stops. Quick check without that: Settings, Back up and restore, Restore opens the same kind of chooser; if that shows nothing, the tablet has no file chooser app at all. The addresses Gemini uses to upload were checked against Kestrel ad and tracker lists and are not blocked. NOT run on the tablet.
