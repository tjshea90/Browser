alpha81: live diagnostics for Claude (your idea: browse normally, the browser quietly records what goes wrong, Claude reads it and fixes the browser from real data). It is OFF-able and private by design. Settings, Live diagnostics (for Claude). WHAT IT NOTES: crashes and kills of the last run, freezes, slow page loads by site name, Back problems, video stalls and decoder errors, memory, pages that do not work. WHAT IS NEVER NOTED OR SENT: passwords, anything you type, cookies, page text, page titles, file or video names, card numbers, e-mail addresses, phone numbers, tokens. Web addresses are cut down to the site name only (never the path or what follows it). Banking, health, mail, government, school and sign-in or account or checkout sites are not even named. Private tabs are never named. All of that is removed ON THE TABLET before anything is kept; a line that still looks risky is dropped. WHERE IT GOES: only to your PRIVATE GitHub repository kestrel-private, with your own token (one repository, Contents read and write), typed into Settings once; it stays in this app only (not in backups, not in the APK). If the repository is ever public, nothing is sent. At most 4 small files a day, 6 hours apart (a crash sooner), only while the app is in front. THE OFF SWITCH: Settings, Live diagnostics, off = nothing is recorded, what was kept is erased at once, nothing is ever sent. Also: Send now, Erase what is stored. Without a token nothing leaves the tablet. NOT RUN ON THE TABLET and not run against the real GitHub: your first Send now is the first real test. Claude sessions read the files with tools/diag_digest.py.
