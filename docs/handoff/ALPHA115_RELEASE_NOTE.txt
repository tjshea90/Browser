alpha115: downloads that a page makes itself, like Proton Drive, now save. WHAT YOU SAW: a zip from Proton Drive failed in Kestrel G with The site sent a web page instead of the file, and the same file downloaded fine in Brave. WHY: Proton Drive does not keep your file on a web address. Its page decrypts the file inside the browser and hands it out of a small background program (a service worker) that exists only inside the engine. Kestrel's download manager used to throw away what the engine offered and ask the website for the same address again, and the website answers that with its start page, not your file. Brave saves what its engine hands over, so it worked there. WHAT CHANGED: Kestrel now keeps the engine's own stream for up to three minutes. When the address cannot be asked for again (a Proton Drive stream, a blob address), or the website's answer is an error or a web page, the file is saved straight from the engine's stream. Ordinary links work as before, with several connections and pause and resume; the engine's copy is simply closed unused. A file a page makes itself cannot be paused or resumed: its row offers Cancel only while it runs, it starts at once ahead of other waiting downloads, it is never sent to the phone, it ignores the speed limit, and its tab is not put to sleep while it runs. If it is cut (the page was closed, the app stopped) the row says the page made this file itself and to go back to the page and download it again, and the half file is removed. Downloads from blob: addresses now work too (they used to fail with This address cannot be downloaded). New counters download.handed.offered, ordinary, used and gone show in the next diagnostics. NOT RUN: there is no Proton Drive account and no Firefox engine in the build sandbox, so the proof here is 17 new tests of the download engine (with a stand-in for the service worker stream, a cut stream, a blob file, an ordinary link and a one-time link) plus the full unit test suites. Please try the same zip again in Kestrel G on the tablet. The Kestrel WebView build is not changed and cannot save such files.
