alpha69: your two messages after alpha68 (the YouTube crash and the download manager popping up). (1) THE DOWNLOAD MANAGER NO LONGER POPS UP BY ITSELF. I found two causes by reading the code. First, after you tapped a download notification once, Android kept that tap on Kestrel and played it again every time it restarted the app (after a crash, after taking the app for memory, from Recents), so the Downloads list opened on its own; now only a real tap on a notification opens it, and a replay after a restart is ignored. Second, the small download window at the top right treated every old download as new when Kestrel started (and any download that carried on by itself after a restart); now it comes up only for a download you start, or one you resume yourself, and old downloads never bring it up. (2) THE YOUTUBE CRASH: I could not prove the cause. The Diagnostics you sent has no crash note and no engine crash report, so it was not a Java crash and not one the engine could report; the page list and the engine state also disagreed, which means the last run ended abruptly. The most likely cause is Android taking the whole app for memory on a 2 GB tablet while YouTube was loading, but that is a conclusion by elimination. A test run on the simulated tablet could not decide it either (the simulator itself broke down on YouTube). So this release makes the next time provable: Kestrel keeps a small note of how each run ended, written only when something notable happens (no timers), and Diagnostics has a new line Last run that says whether the last run ended on purpose, in the background, or while on screen, and for the last case the likely cause (crash note, tablet restart, engine crash, or ended from outside), the free memory and the last events. If it happens again, open Menu then Diagnostics as soon as the app is back and send me the text. Checked on a simulated Android 10 tablet with the real Firefox engine: the app killed from outside while in front and in the background, and the Diagnostics line after it. NOT proven on the tablet: the download list no longer opening after a restart (tap a download notification once, close the app, open it again from Recents) and the quiet small window at start; the Last run line on real hardware. Also new in your Diagnostics: downloads lines that say why the window or the list came up.
