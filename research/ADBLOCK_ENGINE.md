Evidence stayed in the session scratchpad, outside the repo: shallow clones of uBlock (2bc679d), uAssets (bafdbd3), ghostery/adblocker 2.20.3, brave/adblock-rust 0.13.5, brave/adblock-resources, Hagezi; GeckoView 160 `classes.jar` (javap) and unpacked omni.ja; a JS port of our matcher; Playwright crawls. ## 1. Decision

1. **Decide every request inside the extension, in plain JS over typed arrays (option b). Delete the per-request native message.** [V] Cause of the jank: `WebExtension$Listener` registers `GeckoView:WebExtension:Message|PortMessage|Connect|Disconnect` with `EventDispatcher.registerUiThreadListener`, so each `sendNativeMessage` is served on the Android UI thread while Gecko holds the request. `ShieldsBridge` then does JSON, pref reads, `Log.d` and, per BLOCKED request, `updateUi()` -> `Toolbar.bind()` (2x `setImageResource`, text, layout). Ad-heavy pages block 100-1,000 requests per load (section 5). research/FREEZE.md reaches the same diagnosis and files this under P2; this report says P0 (the work is ~5 days, section 3).
2. **One compiler, two readers.** `:core` (parser, builder, canaries, PSL) stays the only list compiler. Add a little-endian, 4-byte-aligned `KFS2` writer so the extension maps sections as `Int32Array`/`Uint32Array` views (zero copy). Prototype [V] (scratch, not committed): a 250-line JS port reads today's UNCHANGED `default.kfs` and returns identical verdict words (block, category, `$important`, exception) to the Kotlin engine on **141,443 requests built from the real lists: 0 mismatches**. Load 7 ms (big-endian byte swap; KFS2 removes it), 2.6 MB typed arrays for the network part, **5.2 us/request average on x86 V8**, 35 us for an ad-like URL with ~140 candidate rules, <= 0.9 ms for crafted 2 KB URLs. [E] A53 + SpiderMonkey is 5-10x slower: 25-50 us average, still far below a UI-thread round trip under load.
3. **Rejected: declarativeNetRequest.** [V] Gecko 160 allows 30,000 static rules per extension (`extensions.dnr.guaranteed_minimum_static_rules`; the extra global pool is a commented-out TODO, bug 1803370), 5,000 dynamic, 1,000 regex, and matches by a linear JS scan of every rule per request (`ExtensionDNR.sys.mjs`, `#collectMatchInRuleset`). We compile ~120,000 network rules.
4. **Rejected as the default engine: bundling uBlock Origin.** It is the quality ceiling, so use it as (i) the source of scriptlets and neutered redirect resources (GPLv3, pinned release), (ii) a parser oracle in tests, (iii) a one-day "APK with uBO built in" spike to measure memory and start-up on the tablet. Against: it needs tab ids, `tabs.*` events, `setTabActive`, popup hosting through `ActionDelegate` (none wired in our app), 1-4 s compile/load with requests suspended, its own updater and UI, and no hook for our Shields panel/counters (section 8).
5. **Brave's engine (adblock-rust to WASM) is a P2 spike, not P0.** Its CI builds `wasm32-unknown-unknown` but there are no maintained JS bindings; its flatbuffer DAT costs "about 15 MB for ~100k filters" [E, from Brave's "-75%, ~45 MB saved"], ours 2.6 MB for 120k. Re-open if our own cosmetic/scriptlet work fails the diff targets in section 3.
6. **Keep the Kotlin engine** for the WebView build, main-frame/malware checks (`NavPolicy`), popup checks and `isPageAllowed`. Stop-gap if D1 slips: FREEZE.md P0 (worker thread + `GeckoResult.complete`, counters <= 4 Hz); delete it when D1 lands.
7. **Process model.** Keep `extensionsProcessEnabled(false)` for P0 (JS then runs on the Gecko parent main thread, not the Android UI thread). Risk: Mozilla calls it "not really supported" (bug 1880856, Rob Wu) and lists blank extension pages and a file-input crash as consequences. Ship FREEZE.md's hidden A/B switch "extensions process ON" (blocking callback then costs a parent<->extension IPC, [E] +0.2-1 ms, but no parent-thread JS). Same engine code either way; decide with tablet numbers.
8. **Lists (section 6).** Network coverage is EasyList + EasyPrivacy. Add uBO `quick-fixes`, `resource-abuse`, `annoyances-cookies`, `privacy-removeparam` (payload is scriptlets/redirects/removeparam, not hosts) and **Hagezi Light** (+3.3 points of blocked requests for +80k hosts = +0.8 MB `.kfs`). Skip Hagezi Pro, OISD, Peter Lowe, URLhaus-URL. Build the snapshot in GitHub Actions (canaries first) and let devices download ONE ~2.1 MB gzip instead of compiling 7 lists.
9. **Video-site ads (section 9).** Needs scriptlets (json-prune family, trusted-replace-*, set-constant) plus HTML filtering. Ship as an explicit Settings switch whose text says YouTube's terms forbid circumventing its ads and YouTube may limit playback. Owner decides the default (Brave and uBO ship it on).
10. **Licence.** Recommend GPLv3-or-later for the repo: reusing uBO scriptlets requires it, EasyList (GPLv3+/CC BY-SA 3.0), uAssets, Hagezi, AdGuard are GPLv3 data, GeckoView/Ghostery/Brave are MPL-2.0 (GPL-compatible). Record every licence in `docs/FILTER-LISTS.md` (table in section 6).

## 2. Target architecture (Kestrel G)

```
Kotlin app (UI process)                                 kestrel-shields v2 (built-in MV2 extension, persistent background)
 Prefs + SiteShieldStore ---- Port JSON text, rare ---> settings: global flags + per-host mask/values (replaces Shields.effective)
 FilterUpdater (conditional GET of CI snapshot) -------> snapshot bytes (bundled copy first; chunked Port or file:// - spike)
 Tab counters  <--- <= 1 msg/s per tab, batched ------- engine.js: KFS2 views; check(url, topHost, type) -> verdict   (sync)
 Kotlin FilterSet: NavPolicy, popups, malware            webRequest.onBeforeRequest {blocking, types without main_frame} -> {cancel} | {redirectUrl}
                                                         content.js (document_start): site CSS + class/id survey -> background (in-process)
                                                         scriptlets: contentScripts.register({world:'MAIN', runAt:'document_start', matchOriginAsFallback})
```
- **Per-request path touches only the extension.** Page host comes from `webNavigation`/`frameAncestors` into a per-tab record; `check()` is synchronous and returns `{cancel:true}`; no promise, no message. Counters are typed-array increments flushed once a second per tab with changes; the toolbar chip updates at most 4x/s.
- **KFS2** adds sections the Kotlin builder must now emit instead of skipping: generic cosmetics as class/id hash sets, per-host scriptlet calls (name id + args), redirect and removeparam side tables, procedural selectors, HTML filters. 64-bit hashes stay (hi/lo `Int32Array` pairs, sorted signed-hi/unsigned-lo; my port proved the FNV-1a+murmur finaliser is exact with 32-bit limbs). Header: magic, version, section table (id, offset, length), CRC32 verified on download only.
- **Update path.** Scheduled workflow (separate from the APK workflow) builds `kestrel-lists.kfs2.gz` + sha256 + manifest, runs `DefaultListsRegressionTest` and the differential corpus, publishes a rolling release asset; the app does a conditional GET weekly (metered rules unchanged), swaps atomically, keeps the bundled copy as fallback. Compressed size [V]: `default.kfs` 4.40 MB -> 2.10 MB gzip, versus 2.37 MB gzip for the 15 raw lists plus ~0.8 s x86 (est. 6-10 s on A53) of parsing the tablet no longer does.
- **Pitfall [V]:** `ensureBuiltIn` reinstalls only when `manifest.json` `version` differs (`GeckoViewWebExtension.sys.mjs`); ours is a constant "1.0". Generate the version from Gradle/commit or a changed `background.js` never reaches users who already installed.
- **Private tabs [V]:** built-in = privileged, and `_setupStartupPermissions` auto-grants `internal:privateBrowsingAllowed`, so the extension sees private requests. Keep a test.
- **Security model:** only lists built by our CI may call `trusted-*` scriptlets (uBO and AdGuard use the same rule); user lists never.

## 4. How the best engines work (evidence)

- **uBO static filtering [V source]** (`static-net-filtering.js`, 6,124 lines): all filters live in one `Int32Array` arena; pure hostnames in `HNTrieContainer` (reversed hostnames, typed-array compressed trie, WASM-able matcher), plain patterns in a `BidiTrie`; each filter is indexed by the best token of up to 7 chars chosen by "badness" using the top-100 "bad tokens" histogram from 200k+ benchmark URLs; buckets with >= 3 members are merged into tries; precedence `important` > `@@` > block; `$badfilter` removes the exact filter; `redirect`, `csp`, `removeparam`, `permissions`, `urlskip`, `replace` are separate "realms". A serialized "selfie" (LZ4) avoids recompiling at launch, and by default requests are suspended until lists are loaded (the wiki warns that disabling this lets first-page requests through). `@gorhill/ubo-core` 0.1.30 (GPL-3.0-or-later, "API subject to change at any time") packages only this engine.
- **uBO cosmetics/scriptlets [V source]**: specific by hostname (entity and regex allowed); "lowly generic" selectors keyed by class/id token, found by a DOM surveyor that reports new tokens in batches and shuts itself down after 256 fruitless surveys/5 min; "highly generic" ones always injected; procedural filterer loaded on demand; CSS inserted as user-origin stylesheet; HTML filtering `##^` through stream filters; scriptlets pre-registered per host with `contentScripts.register({world:'MAIN', runAt:'document_start', matchOriginAsFallback:true})` on Firefox >= 128 (fallback: inline script, then blob); `trusted-*` scriptlets only from trusted lists; CNAME uncloaking with `dns.resolve(host, ['canonical_name'])`; differential list updates (`diff-updater.js`, 285 lines).
- **uBO syntax semantics [V wiki]**: `1p/3p` compare base domains (`strict1p/3p` hostnames); `domain=`/`from=` take `|` lists with `~`, entities, regex; `to=` is a superset of `denyallow=` (which needs `domain=`); `important` ignores `@@`; `badfilter` disables the matching filter; `csp=` needs a matching exception text; `redirect=name:priority`; `replace`, `uritransform`, `urlskip` are trusted-only; `header=`, `method=`, `cname` (exception-only), `popup`, `all` (adds popup, document, inline-script/font); dynamic filtering rows are source/destination/type/action with `allow` > `block` > static exceptions, switches `no-large-media`, `no-remote-fonts`, `no-popups`, `no-scripting`; "medium mode" = `* * 3p-script block` + `* * 3p-frame block` ("significantly faster", "high likelihood of breakage", no figures).
- **Brave adblock-rust 0.13.5 [V repo, blog]**: MPL-2.0, network + cosmetic + resources (`use_resources`), `hidden_class_id_selectors`, `url_cosmetic_resources`; `$method`, `$badfilter`, `$important`, `$redirect(-rule)`, `$csp`, `$removeparam` (simple names; regex unsupported); procedural operators parsed (`has-text`, `matches-css`, `upward`); flatbuffer DAT v7; changelog: "skip flatbuffer verification for DAT files created and read by the same library version", `%` as tokenization delimiter. Brave posts: 69x faster than its old C++ blocker, **5.7 us average per request** on EasyList + EasyPrivacy (55k rules, 242,944 requests, 2018 MacBook Pro i7); v1.85 flatbuffers cut memory 75%, "roughly 45 MB" with ~100k default filters, all platforms, +13% matching speed from tokenizing common regexes. Brave's own resources: 17 files (`brave-youtube-*`, `brave-yt-sabr-fix.js`, `vaft-ublock-origin.js`, `video-swap-new-ublock-origin.js`, `de-amp.js`, `trusted_types.js`).
- **Ghostery adblocker 2.20.3 [V repo]**: MPL-2.0 TypeScript, active (release 2026-10-28); `serialize()`/`deserialize()` to `Uint8Array`; supports `to`, `denyallow`, `domain`/`from`, `badfilter`, `important`, `redirect(-rule)`, `csp`, `removeparam` (not regex), `replace`, HTML filters, `+js` with uBO resources, extended selectors. 2019 vendor study: median 7 us/request, 1.8 MB engine memory in Chrome [old, vendor]. Good fallback source for procedural selectors; not adopted wholesale because it would replace our tested matcher and its canaries.
- **AdGuard [V pages]**: libraries and filters GPL-3.0 (tsurlfilter, tswebextension, Scriptlets, agtree; AdguardFilters). Extra syntax: `$cookie`, `$hls`, `$jsonprune`, `$xmlprune`, `$removeheader`, `$referrerpolicy`, `$stealth`, `$network`, `$app`, `$dnstype`, Extended CSS; scriptlets accept uBO names; trusted scriptlets restricted to approved sources. Filters: Base, Tracking Protection, URL Tracking, Social, Mobile Ads, Annoyances (Cookie Notices, Popups, Mobile App Banners, Widgets, Other).
- **Mobile numbers.** Published: Brave -45 MB (above); Ghostery 1.8 MB (2019). uBO: no current memory figure found [N]; Mozilla bug 1651434 (desktop, 2020): ~3.5 s init, a first-install compile ~4 s then ~1 s load; bug 1428573 (Fennec, 2018): 12.1 s start-up with uBO + HTTPS Everywhere vs 2 s bare. Mine [V]: network arrays 2.6 MB, 5.2 us/request, 7 ms load on x86.

## 8. Options (a)-(d) against GeckoView 160 [V unless tagged]

| | (a) Kotlin + native messaging (today) | (b) JS engine in the extension | (c) declarativeNetRequest | (d) uBlock Origin built in |
|---|---|---|---|---|
| UI-thread work per request | all of it | none | none | none |
| Fit with 120k rules | yes | yes | no (30k cap, linear scan) | yes |
| Scriptlets / procedural / redirects | no | yes (P1/P2) | redirects and removeparam only; no scriptlets | yes, all |
| Our Shields switches + counters | yes | yes (Port + batched) | partial | no clean hook |
| Memory / start-up on A53 | known | 2.6-4.4 MB, ms load [E tens of ms] | Gecko JS rule objects [N] | unknown, 1-4 s compile/load |
| Testable in Node and desktop Firefox | no | yes | partly | yes (it is an add-on) |

- **GeckoView facts for (d) [V]**: extension APIs present in 160: `webRequest` (blocking, `filterResponseData`), `webNavigation`, `dns`, `scripting`/`contentScripts` with `world:MAIN`, `publicSuffix` (no PSL file needed), `storage`, `alarms`, `cookies`, `privacy`, GeckoView `tabs` (incl. `insertCSS`, `executeScript`, `query`), `browserAction`/`pageAction`. Absent: `menus`, `commands`, `windows`, `sidebarAction` (Mozilla's Android differences page). uBO's Firefox manifest declares `gecko_android` >= 128, `popup-fenix.html`, MV2 background page, permissions `dns`, `menus`, `privacy`, `webNavigation`, `webRequestBlocking`, `unlimitedStorage`. Popups come through `ActionDelegate.onTogglePopup/onOpenPopup` returning a `GeckoSession` we must host; built-in install via `ensureBuiltIn` needs no signature; nothing in our app calls `setTabActive`, `setActionDelegate` or `SessionTabDelegate` yet, and hibernated tabs would vanish from uBO's tab model.
- **Native messaging fine print [V]**: Mozilla's Android page lists `sendNativeMessage` as unsupported for regular Android extensions; it works for us only because built-in + `geckoViewAddons`; replies must be plain strings.
- **Firefox keeps blocking `webRequest` in MV3** and ships DNR beside it (Mozilla add-ons blog, 2022); event pages, not service workers. Stay MV2 persistent: the engine must not be unloaded.
- **GPL in (d)**: bundling uBO unmodified is an aggregate; modifying it means publishing the changes. The repo is public, so the cost is the licence choice in section 1.10.

## 9. YouTube and other video-site ads [V uAssets Nov 2026]

- Current uBO rules (quick-fixes + filters): `json-prune` of `playerResponse.adPlacements|playerAds|adSlots`, `json-prune-fetch-response` / `-xhr-response` on `/player` and `/playlist`, `set-constant` `ytInitialPlayerResponse.adPlacements|playerAds|adSlots = undefined`, `trusted-replace-xhr-response` / `trusted-replace-fetch-response` (`"adPlacements"` -> `"no_ads"`), `trusted-edit-inbound-object` on `JSON.stringify` (10 rules, rewrites client context such as `isInlinePlaybackNoAd`), `trusted-prevent-dom-bypass`, `adjust-setTimeout`, `remove-node-text`, `no-xhr-if` for `atr` pings, and HTML filter `##^script[id]:has-text(window,"fetch")` (needs stream filters, Firefox-only). Brave adds its own resources (`brave-yt-sabr-fix.js`, navigation/theater/playback-speed fixes) and Twitch scripts (`vaft-ublock-origin.js`, `video-swap-new-ublock-origin.js`).
- Needed from us: P1 scriptlets (json-prune family, trusted-replace-*, set-constant, edit-inbound-object, prevent-dom-bypass) + P2 HTML filtering, plus the 8-hour `quick-fixes` refresh. Expect breakage: Ghostery reports detection logic changing "twice to multiple times per day", server-side ad insertion, and a warning shown after about three videos when logged in.
- **ToS/legal caveat, to state honestly in the UI:** YouTube's Terms (Permissions and Restrictions) forbid users to "circumvent, disable, fraudulently engage with, or otherwise interfere with any part of the Service"; YouTube told the press that ad blockers violate its terms. The consequence is contractual (warnings, playback limits, possible account action), not criminal law in most places [S, not legal advice]. Make it a labelled switch; do not hide it.

## 10. Measuring "unnecessary page weight" in CI

- **Policies safe by default**: ads/trackers/cookie-sync (section 5), cosmetic hiding, neutered shims for GA/GTM/GPT/IMA so pages keep working, tracking-parameter stripping, cookie-notice rules with `set-cookie` scriptlets, `preload=none` media, autoplay off (GeckoView `PERMISSION_AUTOPLAY_*`; see GECKO_SPEED.md), HTTPS-first.
- **Opt-in "Aggressive"**: EasyList social/chat/AI/newsletter/notification lists, click-to-load for embeds (Disqus 72 requests; uBO ships `click2load.html`), `webFontsEnabled(false)` (4% of remaining bytes; icon fonts break), block third-party frames. **"Strict" = uBO medium mode** (3p scripts and frames blocked, per-site relax); power users only.
- **Harness** (P1): same pages, configs {off, current lists, candidate}, N >= 5 alternating, medians of requests, distinct hosts, transfer bytes, DOMContentLoaded, load, last network activity, CPU time of the content process. Hard gates on a local fixture site (fake ad hosts mapped with `network.dns.localDomains`); live pages as a nightly soft trend. Load the real extension in desktop Firefox with Selenium + geckodriver (`moz/addon/install`, temporary) or WebDriver BiDi `webExtension.install` (unsigned = temporary; Mozilla docs); Playwright/Puppeteer do not officially load Firefox extensions, hence Chromium for the numbers above.

## 11. Not verified / risks

- Every on-device number: A53 + SpiderMonkey + GeckoView speed and memory of any engine; the A53 factor (5-10x) is a rule of thumb. The UI-thread mechanism is verified in bytecode and source, its share of the typing freeze is not profiled.
- Transport of a multi-MB snapshot over native messaging, `file://` fetch from a built-in extension, `Uint8Array.fromBase64` in 160: unknown (P0.3 spike).
- Crawl: one pass, bot-walled sites dropped, headless Chromium not Firefox, no consent clicks, no cosmetic or scriptlet effect, ads rotate. Treat percentages as orders of magnitude. ETP strict (Disconnect lists) may double-count with our lists: not measured (GECKO_SPEED.md).
- uBO memory/start-up on this tablet; Hagezi false positives on logged-in pages; AdGuard Base size; real `Diff-Path` patch sizes; OISD and "I don't care about cookies" licences; CNAME `canonical_name` over DoH/TRR; adblock-rust WASM size and speed on ARM32; whether YouTube fixes still work on the day of shipping.
- The JS port skips the Kotlin >2048-character/userinfo handling and the cosmetic tables; both must be ported before shipping.
