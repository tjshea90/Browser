## Checked and fine (do not re-audit)
- Extension manifest: no externally_connectable, web_accessible_resources only embed.html and embed.js (embed.js loads only http(s) and the click is the user's), CSP equals the MV2 default, no eval / Function / innerHTML / document.write / postMessage listener anywhere in the extension scripts (grep over all 21 files); only one runtime.onMessage listener and every handler checks sender.tab / frameId or clamps its numbers; ShieldsBridge checks extension id and environment type (ShieldsBridge.kt:110).
- Page-to-extension bridge events: __kst_pop (kinds allow-listed, tap / vmenu never believed), __kst_gate_rep, __kst_codec_rep (numbers range-checked, 8-10 per document), __kst_gate_ask (all fields clamped; only the SC1 consequence is open); quality.js reads page objects through wrappedJSObject but only reads strings and numbers and cuts them again in background.js and in the app.
- Scriptlets: trusted-* names are refused for untrusted lists in Kotlin (ScriptletRules.kt:147-178), the early script embeds the payload with JSON.stringify of a string, the library runs in the page world only, a page that fires the event itself gains nothing it did not have; cosmetic CSS is sanitized hard (no braces, url(), @, backslash, image-set; :style() allow-list of characters, 300/120 length caps).
- Network filter rules from lists: regex rules are skipped (Skip.REGEX), so no ReDoS in the matcher; .kfs reader checks CRC, array lengths against remaining bytes, offsets, sort order and an empty probe slot (FilterSetCodec.kt:62-142); the extension image is capped at 64 MB and chunk overrun is checked.
- FilterUpdater: https only, 14 MB cap per list, HTML rejected, minimum 20,000 rules and 60 % of the old count, canary URLs allowed / blocked, codec round trip, temp file then rename; HttpURLConnection does not follow https to http, and the Gecko build ships only the lists named in FilterSources.
- Android layer: only MainActivity exported (both builds), services and receivers not exported, HandOverProvider not exported and one safe path segment, PendingIntents immutable except the installer one (explicit component), allowBackup false plus extraction rules, file picker accepts content:// only, debug lab intents and DebugProps need FLAG_DEBUGGABLE, no clipboard reads outside the debug lab, urlFromIntent accepts only http(s), ACTION_SEND text goes through Omnibox.resolve.
- Page-named links: linkMenu / imageMenu offer "open" only for web URLs; ExternalIntents blocks file, content, javascript, data and friends, refuses its own package and app.kestrel extras; the PAC for "pages through the phone" embeds the Wi-Fi gateway IPv4 only, so it cannot be injected.
- Courier: HMAC compare is constant time, 60 s window plus replay guard plus throttle, PeerGuard and Ssrf handle mapped and NAT64, proxy refuses private destinations and is armed per tablet address by a signed call.
- Private tabs: thumbnails and Back pictures stay in RAM (BrowserActivity.kt:2123), private download notifications say "A private download" / "Downloading (private)", no persistence of private sessions, private tab URLs not in the progress or finished notifications.
- CI: tag or manual dispatch only, inputs go through env, actions pinned to SHAs, per-job write permission, the lab workflow has no secrets and uploads text and screenshots only. The signing material is still written next to a Gradle run (B3, tracked).
- WebView build: JsEscape.quote for injected CSS, no addJavascriptInterface, SSL errors cancel.
