## Verified OK by the reviewer (do not re-audit)
- Manifests: only MainActivity exported; services, receivers, provider not; allowBackup=false + extraction rules; PendingIntents IMMUTABLE (installer one has an explicit component); HandOverProvider read-only, one path segment.
- Bridge: ShieldsBridge.kt:110 checks the extension id and environment type; `embed-allow` checks `sender.url` (background.js:570); redirect stand-ins are data: URLs; forged page `tap` / `vmenu` ignored (content.js:499-508); hand-over to the own player needs an app-side touch + user activation.
- Debug lab intents need FLAG_DEBUGGABLE (BrowserActivity.kt:941).
- External intents: action allowlist, component + selector nulled, grant flags stripped, user gesture + confirm; omnibox rejects javascript:, data:, file:, content:, intent:; prettyUrl drops userinfo.
- Permissions: only geolocation, camera, microphone asked; notifications, popups, storage-access denied.
- Private tabs: FLAG_SECURE, not persisted, thumbnails skipped. Downloads: names through FileNames.sanitize, constant MediaStore RELATIVE_PATH, numeric staging ids, fetcher follows only http(s), refuses https->http, drops Cookie / Authorization across hosts.
- Updates: SHA-256 + PackageInstaller signature pin + versionCode check; receiver not exported. WebView build: no addJavascriptInterface, file / content access off, mixed content never, SSL errors cancel.
- Engine: remote debugging and about:config off, LNA on with blocking, enterprise roots off. Courier: constant-time HMAC compare, PeerGuard / Ssrf handle v4-mapped and NAT64. CI: inputs via env, actions SHA-pinned, read-only default token, no pull_request_target.
